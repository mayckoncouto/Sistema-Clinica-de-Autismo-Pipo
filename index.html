Sistema de atendimentos
conectando…
Modo somente leitura — você está vendo esta agenda mas as alterações não serão salvas. Verifique se está conectado com uma conta que tem permissão de edição.
Não faz ABA 0–4 anos 5–9 anos 10+ anos
Clique numa célula para agendar, editar ou desmarcar. Arraste um atendimento para outro horário para movê-lo (solte sobre uma célula ocupada para trocar os dois). Use o ícone de cópia para colar em outro dia ou semana. Clique no lápis no cabeçalho de uma sala para editar nome, cor e terapeutas. Alterações são sincronizadas automaticamente para toda a equipe.
Profissionais
Cadastro central da equipe. Os terapeutas selecionáveis nas colunas das salas vêm desta lista.
Salas de atendimento
Cada sala vira um grupo de colunas na grade. Use as setas para reordenar e o lápis para editar nome, cor e terapeutas.
Relatório de atendimentos
Sessões por paciente e por profissional, somando os 4 ciclos de semana da agenda.
